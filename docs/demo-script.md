# Demo Script

This script is designed for a 2-3 minute public demo video.

## Goal

Show that ColorChain is a working independent mobile-first P2P prototype.

## Setup

- one Android node
- one JVM/desktop node
- optional second Android node
- local network or controlled test network
- visible logs or UI state

## Recording flow

1. Show project/repository.
2. Start JVM node.
3. Start Android node.
4. Show connection evidence.
5. Create/send a test message or block.
6. Show propagation/synchronization.
7. Show block hash/height/log evidence.
8. Show trust metadata.
9. Explain that AI signals are advisory.
10. Close with roadmap.

## Narration

ColorChain is an independent mobile-first peer-to-peer network for resilient public-interest information sharing.

It does not rely on a central server or external blockchain ecosystem.

This demo shows mobile and desktop nodes connecting, creating or receiving data, and synchronizing block-based records.

The AI-assisted trust layer provides advisory metadata and does not censor content.

In this recording, the desktop node starts first, the Android node joins, and the connection state becomes visible through logs or UI status.

Next, a test message or block is created so that propagation and synchronization can be observed directly.

The demo then shows canonical block or message evidence such as hash values, height, and synchronization logs.

Finally, a trust metadata example is displayed to show how advisory spam, duplication, and manipulation-risk signals may be attached without removing user content or replacing human judgment.

## Minimal demo

The minimal public demo should show one JVM/desktop node, one Android node, successful connection, one message or block event, synchronization evidence, and one example of advisory trust metadata.

## Strong demo

A stronger public demo should show three or more nodes, including at least one Android node and one JVM/desktop node, repeated propagation events, reconnect behavior, visible synchronization logs, and multiple examples of advisory trust metadata across different message types.
