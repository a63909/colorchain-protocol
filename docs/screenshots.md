# Screenshot Evidence Plan

No screenshots are included in this repository yet. This document defines the evidence checklist for the public demo package.

The demo and grant package should include screenshot evidence for:

- Android node running
- JVM/desktop node running
- peer connection evidence
- block height / hash evidence
- synchronization logs
- message/block propagation
- trust metadata example
- repository/documentation evidence

## Suggested media folder

Screenshots and demo assets should be placed under:

`media/`

## Naming convention

- `media/01-android-node-running.png`
- `media/02-jvm-node-running.png`
- `media/03-peer-connection.png`
- `media/04-block-sync.png`
- `media/05-trust-metadata.png`
